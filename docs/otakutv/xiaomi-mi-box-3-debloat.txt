# Xiaomi Mi Box 3 (model MIBOX3, codename once, Amlogic), Android TV 9 (SDK 28), firmware PI.3934,
# 2 GB RAM, 1920x1080. Tested with OtakuTV 0.1.0 on 2026-11-17 and 2026-11-18.
#
# Apply:   tools\disable.ps1 -TvHost <box ip> docs\otakutv\xiaomi-mi-box-3-debloat.txt
# Undo:    tools\restore.ps1 -TvHost <box ip> docs\otakutv\xiaomi-mi-box-3-debloat.txt
# Everything is DISABLED, not uninstalled. Comment out (#) any line you want to keep.
#
# Notes from this box (details in docs/otakutv/AUDIT-mibox3.md):
# - The Xiaomi update service is disabled BEFORE PatchWall: left enabled, it installs PatchWall again
#   a few minutes after you disable it. With this order PatchWall stayed off.
# - Kept on purpose, not in this list: the voice assistant (com.google.android.katniss,
#   com.google.android.speech.pumpkin), Chromecast (com.google.android.apps.mediashell), the Google
#   screensaver (com.google.android.backdrop), the phone remote (com.google.android.tv.remote.service),
#   Mi cast (com.mitv.milinkservice, com.mitv.videoplayer).
# - Leave alone: com.xiaomi.android.tvsetup.partnercustomizer (remote shortcut buttons), mitv.service,
#   com.droidlogic* (Amlogic system, Bluetooth, NTP), com.google.android.tungsten.setupwraith.
# - Firmware updater: this list disables com.xiaomi.mitv.updateservice because it is also the channel
#   that re-installs PatchWall. Enable it again to check for a firmware update.
# - Measured: free RAM 979 MB before, 1.12 GB after the list (same session, no reboot).
